# SecureLint Pro

Semgrep-powered VS Code extension for **JavaScript**, **TypeScript**, and **Python**.

- **Hardcoded secrets** → Quick Fix to env var
- **Missing authorization** → Quick Fix adds guard

## Run
```bash
npm install
npm run compile
# Press F5 (Run Extension)
```

If needed, set Settings → securelintPro.semgrepPath or rulesFolder.
